# P2 Introducción a C

Durante el desarrollo de esta práctica realizarás las siguientes tareas: 

- Trabajar con el preprocesador de C. 
- Compilar y enlazar programas en C manualmente 
- Entendiendo las fases de preprocesado, compilación y enlazado. 
- Usar la herramienta make con un Makefile sencillo 
- Crear dependencias y comprobar la reconstrucción automática de objetivos. 
- Programar ejemplos en C con 
- Punteros, arrays, cadenas, memoria dinámica, structs y punteros a funciones. 
- Completar e implementar un módulo para gestionar procesos en C 
- Probar el programa de simulación de procesos en Minix. 
- Automatizar la compilación con un Makefile final.
